## Overview

Sugar Bytes Transfigure applies extreme spectral transformations—pitch shifting, time stretching, smearing, and freezing—in real time for creative resampling and experimental sound design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sugar Bytes Transfigure** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Spectral Pitch** | Real-time pitch shifting with phase vocoder for artifact-free results |
| **Time Stretch** | Independent time stretching up to 4x slower or faster |
| **Freeze** | Instant spectral freeze captures and holds any sound indefinitely |
| **Grain Mode** | Granular resynthesis mode adds stochastic texture to frozen spectra |
